Keyboard shortcuts ​

Every default key. Change them in Settings > Shortcuts.

  • Defaults avoid the keys Studio keeps for itself, which never reach a plugin: Delete (it does arrive in the Timeline because the Timeline sets Studio's selection aside), Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+D, Shift+X, O, , and . (Studio's camera keys), and any key you or another plugin bound in Studio's File > Customize Shortcuts (those are global and a plugin cannot read them). That is why paste and duplicate are Shift+V / Shift+D, the frame steps are the arrows, and loop in/out are Shift+I / Shift+O. Copy is Shift+C.
  • Ctrl+Z and Ctrl+Y are Studio's undo and redo; every AcesMotion edit, poses included, is a step. Edit > Undo names the step.
  • Every shortcut is also a Studio plugin action named "AcesMotion: {name}" (no default key there), so you can bind it in Studio's own shortcut editor. Plugin actions fire on press only; hold keys (Space, P, I, Tab, J) fire their release when the plugin action is used.
  • Rebinding inside AcesMotion: every shortcut, in Settings > Shortcuts (right click a row to clear it or reset it). The hold keys also have their field on their own page: Temporary pivot key, Pin key (Shift plus it clears pins), Context IK key and Look through key (Posing page), Timing key (Trajectory page). A key another shortcut already uses in the same place is refused ("X is taken by {name}"), and so are Studio's own Ctrl+C, V, X, D, Z and Y. Reset this group puts them back. Commands can also be bound in Studio's shortcut editor (File > Customize Shortcuts) as global keys.
  • Keys are ignored while a text box has focus.
  • Scope: Timeline works while the Timeline has focus (and hover keys also while the pointer is over it); Viewport works while no AcesMotion window has focus (the 3D view); Any works in either; Inspector is the Inspector window.

Fixed keys inside windows and menus (not rebindable):

  • Menus: Esc closes; Up / Down move (skipping greyed items); Return / Enter run the highlighted item or open its submenu; Right opens a submenu; Left closes a submenu; any other key closes the menu. With the mouse, a submenu opens on hover and stays open while you move into it, even across other items on the way (it closes a moment after you settle on another item). In a narrow window a submenu that can't fit beside its menu opens just below its item. Tooltips of things under an open menu stay hidden. Menu items whose name doesn't say what they do show a tooltip card while hovered (about 250 across the Timeline, viewport, Hub and Inspector menus).
  • On a Mac, Cmd works wherever these pages say Ctrl (snapping flips, multi-select, shortcuts).
  • Text fields: Enter keeps, Esc cancels (Inspector text, asset id, attribute name, rename boxes, search boxes clear on Esc).
  • Number fields (scrub): Shift finer, Ctrl whole numbers, Esc puts the value back.
  • Editor windows: Esc during a drag in the window cancels just that drag. Enter = OK (unless a field is being typed in), Esc = Cancel, Del / Backspace removes the selected point or stop, Ctrl+Z / Ctrl+Y step through the window's changes, F2 / Del over a saved swatch rename / delete it. The Presets menu takes Esc, Up, Down, Home, End, Enter.
  • Ease canvas: Shift snaps a dragged handle to 0.05, Alt ignores snapping.
  • Sequence editor: Shift snaps a dragged point's time to 0.05.
  • Instance picker: Enter picks the first match, Esc closes.
