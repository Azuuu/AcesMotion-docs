Mouse gestures ​

Clicks, drags and modifiers in each window.

Timeline ​

WhereGestureWhat happens
RulerDragScrubs; snaps to markers, keys, regions, peaks, else whole frames; Alt flips snapping. Plays audio snippets over sounds.
RulerRight clickRuler menu (marker, loop, export region, insert/remove time).
RulerMiddle drag, Space+dragPans time.
Marker flag or stemDrag / double click / right clickMoves it (snaps) / renames it / marker menu.
Loop bar, export bracketDrag body / drag an endMoves / resizes the region.
Scene end handleDragChanges the scene length (snaps; Alt flips Snap).
LanesClick a keySelects it.
LanesShift+click, Ctrl+click a keyAdds to / toggles in the selection.
LanesDouble click a main keySelects everything under it.
LanesDrag a keyMoves the selected keys; chip and ghosts; snaps; Alt flips Snap.
LanesCtrl+drag a keyMoves a copy.
LanesDrag on empty laneBox select; Shift / Ctrl adds.
LanesDouble click empty lane space on a rowSelects every key of that row (Shift / Ctrl adds).
LanesDrag a scale handleRetimes the selection about the other end; Shift about the playhead.
LanesDrag the spread handleOffsets joints' keys in time (Random / Alternate / Staircase); drag left for earlier; Alt exact ticks.
LanesClick the spread chipSpread menu (mode, Reroll random).
Action laneClick / Shift+click / Ctrl+click a blockSelects it / adds it / toggles it (keys let go).
Action laneDrag a blockMoves the selected blocks in time (their own tracks); ghosts and a dotted trail; snaps; Alt flips Snap.
Action laneCtrl+drag a blockMoves a copy.
Lanes, action laneDrag a sound bar, burst bar or block up or downMoves that bar to the lane under the pointer (with any time move, one undo step).
Action laneDrag a bar's end gripTrims that end (the other stays; at least one frame); "Length 60 f" read-out.
Action laneDrag or double click on an empty spotBox-selects blocks (into other rows: their keys and blocks) / selects every block of the track.
Action laneRight click a block / an empty spotBlock menu / track menu (Add block at that frame).
Camera rowClick / Shift+click / Ctrl+click a shotSelects its switch key / adds it / toggles it (keys and blocks let go).
Camera rowDrag a shot / Ctrl+dragMoves the selected switch keys in time (taken frames skipped, snaps, Alt flips Snap) / moves a copy.
Camera rowDrag or double click on an empty spotBox-selects switch keys (down into the rows: their keys and blocks instead) / selects them all.
Camera rowDrag a shot's right endCuts the shot short (its Until; no camera live to the next key); onto the next key it runs to it again.
Camera rowRight click a shot / an empty spot / the headerKey menu (Switch to, Start at, End at, Extend to the next switch or scene end, Duplicate, Delete, Show in Inspector) / lane menu (Switch to at that frame, Add camera at view) / header menu (Select all switch keys, Mute, Lock).
LanesRight click a keyKey menu.
LanesRight click a sound fade gripFade menu (shape, remove).
LanesMouse wheelScrolls rows.
Lanes, ruler, graphCtrl+wheel / Shift+wheelZooms time at the cursor / pans time.
LanesCtrl+Shift+wheelCompact or normal rows.
Lanes, ruler, graphMiddle drag, Space+dragPans.
Sound barDrag left edge / right edgeTrims the start (audio stays put) / trims the end.
Sound barDouble click the right edgeClears the end trim.
Sound barCtrl+drag the right edgeStretches the speed (0.25x to 4x).
Sound barDrag a fade grip / a loop handleFades / moves the loop.
Effect barDrag the end grip / the min knobMax life / min life; double click a grip for the emitter's own.
Row headerClick / Ctrl+click / Shift+click / Ctrl+Shift+clickSelect / toggle / range / add range.
Row headerDouble clickKeys the row at the playhead (like K).
Row headerRight clickRow menu.
Row header (sound/effect rows)Drag top or bottom edgeTaller or shorter row; double click resets.
Row headerHoverShows the mute (eye) and lock buttons.
Splitter (Split)DragShares the room between dope rows and curves.
Curve graphClick / Shift / Ctrl a keySelects / adds / toggles.
Curve graphDrag selected keysMoves in time and value; Shift keeps one direction; Alt flips snapping.
Curve graphDrag a tangent handleShapes both sides; Alt shapes one side.
Curve graphWheel / Ctrl+wheel / Shift+wheel / Ctrl+Shift+wheelPans values / zooms time / pans time / zooms values.
Curve graphWheel over the value axisZooms values at the pointer.
Ease canvasDrag a handleShapes the ease live; Shift snaps 0.05; Alt ignores snapping.
Ease presetsClick a card / right click a saved cardApplies it / deletes it (after a confirm).
Status barClick snap, auto-key, fps, lengthOpens the menu or toggles.
ToolbarClick a tool's chevronThe tool's options menu.
Any controlHoverTooltip (0.5 s delay, then instant across neighbours); disabled controls say why.

WhereGestureWhat happens
Number fieldClickTypes a value.
Number fieldDrag left/rightScrubs; Shift finer (10x); Ctrl whole numbers; Esc reverts.
Property rowRight click anywhereRow menu.

Section headerClickFolds it (remembered per class).

WhereGestureWhat happens

WhereGestureWhat happens

Hold TabOver a partTemporary pivot.
Hold IWhile draggingFlips FK/IK.
