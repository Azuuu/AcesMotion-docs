Play it in your game ​

Games play scenes with the runtime, a ModuleScript the plugin writes into your place. Scenes play straight from their data, so there is nothing to upload and they work in any game you own.

1. Install the runtime ​

Open Settings > About and press Install runtime. It writes ReplicatedStorage.AcesMotion. When the plugin updates, the Timeline shows an Update runtime banner.

2. Play a scene ​

From a LocalScript (for example in StarterPlayerScripts):

luau
local AcesMotion = require(game.ReplicatedStorage.AcesMotion)

-- "Scene" is the scene's name; Rig is the actor's role, its name in the Cast tab
local track = AcesMotion.Play("Scene", { Rig = workspace.MyRig })
track.Ended:Wait()

The table is the cast: which instance plays each role. Leave a role out and it plays on the object you animated in Studio. Pass any character with the same rig and the scene plays on it:

luau
local character = game.Players.LocalPlayer.Character
AcesMotion.Play("Wave", { Rig = character })

3. React to markers ​

Add a marker on the Timeline's ruler (right click the ruler where you want it > Add marker at that time), double click its flag to name it, and listen for it:

luau
local track = AcesMotion.Play("Slash", { Attacker = character })
track:GetMarkerSignal("Hit"):Connect(function()
	-- deal damage, shake the screen, play a sound
end)

4. Play it for everyone ​

From the server, PlayForAll plays a scene on every client in sync, and players who join late see it from where it is:

luau
-- A Script on the server
local AcesMotion = require(game.ReplicatedStorage.AcesMotion)
AcesMotion.PlayForAll("Finisher", { Attacker = attacker, Target = target })

Every client requires the runtime

For PlayForAll to reach a player, their client must have required the runtime once. A LocalScript in StarterPlayerScripts with the require line above is enough.

5. Choose where it plays ​

Root motion is measured from the scene's origin. Pass an Anchor and the whole scene plays at that object, and follows it if it moves:

luau
AcesMotion.Play("Summon", cast, { Anchor = character.HumanoidRootPart })

6. Play it in a ViewportFrame ​

Inventory cards, shop previews and reveals play scenes too. Put the rig in the frame's WorldModel first, then play it from a LocalScript:

luau
local world = card.ViewportFrame.WorldModel
local rig = unitModel:Clone()
rig.Parent = world -- (before Play: the runtime looks for the frame when it binds the rig)
local track = AcesMotion.Play("Victory", { Hero = rig }, { Camera = false })

A card that's hidden, closed or scrolled out of its list rests until it shows again, so a full inventory costs only what's on screen. To move the frame's own camera with the scene's, play it with Camera = "Manual" and copy Track:GetCamera into ViewportFrame.CurrentCamera each frame.
