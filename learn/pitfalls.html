Edge cases and pitfalls ​

Common problems and how to fix them.

In the editor ​

A key does nothing ​

  • Studio keeps some keys for itself, even while a plugin window has focus: Delete, Ctrl+C / V / X / D, Shift+X, O, , and .. That's why AcesMotion copies with Shift+C and pastes with Shift+V.
  • A global shortcut can take it. Anything bound in File > Customize Shortcuts wins, and a plugin can't read those bindings. Rebind in Settings or in Studio's editor.
  • The Timeline doesn't have focus. If a Timeline key does nothing, the status bar tells you to click the Timeline. After you leave the Timeline, Studio's W / E / R need a click in the viewport first.

My pose vanished ​

You moved the playhead before keying it. A pose is temporary until you key it, so press K or turn on Auto-key.

A joint spins the long way round ​

The Euler angles flipped past 180 degrees. Select the keys and run Euler filter (key menu), or switch that track to Quaternion rotation mode.

Paste mirrored skipped some joints ​

Paste mirrored leaves out any joint whose rest frame doesn't exactly mirror its partner's, and the status line counts them. Fix the rig's rest pose, or key those joints by hand.

Undo put the rig at rest for a moment ​

This is expected. Studio's undo throws away unrecorded changes, so the preview rests the stand-ins around every undo step and then poses them again.

I deleted my stand-in ​

The Timeline shows a Restore banner. The stand-in's keys are kept.

Particles look different each time I pause ​

Studio can't fast-forward an emitter, so the preview shows frozen copies for the frame you're on. Their arrangement can change from one pause to the next. In a game they play normally.

I hear only snippets while scrubbing ​

Scrubbing plays short snippets on purpose, and playback plays continuous audio. A Sound's own Play() does nothing in edit mode, so the preview uses hidden AudioPlayer copies.

Exporting ​

My export lost the camera and effects ​

A Roblox animation holds one rig's joints only. Cameras, parts, properties, calls, attributes and audio need the runtime. The Export panel lists what won't carry over.

A Constant step looks soft after export ​

Studio samples a CurveAnimation 30 times a second. Export as KeyframeSequence (the default), which plays every key exactly.

Some properties can't be keyed ​

You can't key BrickColor, Font or PhysicalProperties. Use Color3 instead of BrickColor. You pose CFrame properties in the viewport.

In games ​

Nothing plays on clients ​

  • The client never required the runtime (PlayForAll needs every client to require it once).
  • The scene is somewhere clients can't see, such as ServerStorage.
  • The scene was saved with a newer AcesMotion than the runtime in the game. Update the runtime from Settings > About.
luau
-- Quick check in a client's output
local AcesMotion = require(game.ReplicatedStorage.AcesMotion)
print(AcesMotion.Version, AcesMotion.FormatVersion)
local ok, result = pcall(AcesMotion.Load, "Intro")
print(ok, result) -- an error names a missing or too-new scene

A role didn't move ​

A role missing from the cast plays on its fallback. With no fallback, the scene skips it and warns in Studio. Check that the role name matches the Cast tab exactly.

luau
AcesMotion.Play("Slam", { attacker = npc }) -- wrong: roles are case-sensitive
AcesMotion.Play("Slam", { Attacker = npc }) -- right

A server Play didn't take the camera ​

A server Play never takes a camera. Use PlayForAll with Camera = true, or a client Play.

luau
AcesMotion.PlayForAll("Intro", cast, { Camera = true })

Characters jumped at the end of a cutscene ​

Moved actors keep their last root position. FreezeActors and CommitRoot (on by default for PlayForAll) make the server agree with what clients saw. For a server Play, turn them on yourself:

luau
AcesMotion.Play("Knockback", { Target = npc }, { FreezeActors = true, CommitRoot = true })

Late joiners and streaming ​

A player who joins late starts live tracks at the current time. With StreamingEnabled, cast members bind when they stream in, so an actor far away can start late.
