Power users ​

Work faster in the editor ​

  • Shortcuts work on hover. The Timeline takes keyboard focus when the pointer is over it, so most Timeline shortcuts work without a click.
  • Bind anything in Studio. Every shortcut is also a plugin action named "AcesMotion: {name}". Bind it in Studio's File > Customize Shortcuts for a global key.
  • Rebind the hold keys (temporary pivot, pin, context IK, trail timing, look through) in Settings by pressing the new key.
  • Split view. Dope rows go on top and curves below. Tab swaps the lower part between Ease and Channels.
  • Compact rows. Ctrl+Shift + wheel shrinks or grows dope sheet rows.
  • Type a time anywhere. The time field takes 42, f42 or 0.7s. The scene length (status bar) takes 2s, 72f or a bare number.
  • Multi-edit. Select up to 500 objects (keys, rows or the Explorer) and edit them together in the Inspector, as one undo step.
  • Paste to another actor. Select exactly one other actor and paste, and the copied keys land on it.
  • Pop tabs out. Right click a Hub tab > Pop out to put the Inspector or Library in its own window.

Versions ​

  • Save often and name later. Alt+Shift+S (with an AcesMotion window focused) saves a version named by its number. You can name it in the History tab or the Inspector later, once you know it matters.
  • Compare while you work. Compare shows an old version's pose as a ghost over the rig and its keys as faint dots, so you can match timing against a version you liked without leaving the current one.
  • Restore one actor. Select the actors first. A version's Restore selected actors then brings back only their keys and blocks, and leaves the rest of the scene as it is.
  • Branch to try something risky. Branch makes a new scene from any version, and the original keeps going.
  • Keep the automatic versions you need. AcesMotion prunes automatic versions (by default it keeps the newest 5, for 7 days). Keep one, or give it a name, and it stays.
  • Find a message you missed. Click the message in the Timeline status bar to see recent ones, each with its Undo while it still applies.

Move scenes around ​

  • Scene as text (Export) and Import > Scene text carry a whole scene between places.
  • Create N scenes splits a multi-rig scene into one scene per rig. Save as model packs them for another game.
  • Preview id (Export) makes a test AnimationId for the session, so the rig plays the exported clip without uploading. After the first upload, paste the id and pick "Overwrite an existing asset..." to keep the same id in your games.

Runtime tricks ​

  • Drive time yourself. Manual = true stops the runtime from advancing a track, and StepTime and SetTime move it. Use this for a replay scrubber or a slow-motion kill cam:
luau
local track = AcesMotion.Load("Finisher", cast, { Manual = true })
track:Play()
RunService.RenderStepped:Connect(function(dt) track:StepTime(dt * 0.25) end)
  • Read a pose without playing. AcesMotion.Evaluate(scene, seconds, cast) returns every actor's pose by role. It is pure and writes nothing.
  • Swap the cast mid-play. track:SetCast({ Target = newTarget }) lets go of the old instance and binds the new one from that point on.
  • Swap templates per play. The Templates option swaps a spawned role's template for one play (for skins that share a skeleton).
  • Skip far-away scenes. AcesMotion.Configure { MaxDistance = 300 } lets clients skip scenes whose anchor is farther away than that.
  • Listen to every scene at once. AcesMotion.OnEvent("Hit", function(track, payload) ... end) fires for every Event block named Hit in any scene.

Custom actions ​

Anything your game does at a frame can be a block on an action track. Make one with New custom action... in the Add block menu. It writes a typed, commented template where you've selected in the Explorer. Any ModuleScript tagged AcesMotionAction is an action, wherever it lives.

luau
return {
	Name = "Toggle Trail",
	Description = "Turns a trail on for the block.",
	HasDuration = true,
	Params = {
		{ Name = "Part", Type = "ActorPart", Description = "The part holding the trail." },
		{ Name = "TrailName", Type = "String", Default = "SwordTrail" },
	},
	Run = function(context, params)
		local trail = context.GetPart(params.Part):FindFirstChild(params.TrailName)
		trail.Enabled = true
		return function()
			trail.Enabled = false
		end
	end,
}

Blocks preview in Studio while you scrub (context.IsPreview is true there), and the Inspector draws a field for each param.
