Module params ​

Custom actions, generators, constraints and drivers each declare a Params list in their ModuleScript. Each entry becomes a field in the Inspector when one of the module's blocks is selected, and the block's value for it reaches your code under the entry's Name.

The four kinds share the idea but not every detail. Actions take the widest set of types and pass values to Run as they are. Generators, constraints and drivers take fewer types, and their number settings can be keyed over the block.

Example ​

An action that spawns orbs around a hand:

luau
local Action = {
	Name = "Orb Ring",
	HasDuration = true,
	Params = {
		{ Name = "Hand", Type = "ActorPart", Description = "Where the ring is centred." },
		{ Name = "Orb", Type = "Template", Description = "The model copied for each orb." },
		{ Name = "Count", Type = "Integer", Default = 3, Min = 1, Max = 12, Description = "How many orbs." },
		{ Name = "Radius", Type = "Number", Default = 2, Min = 0, Unit = "studs", Description = "How far from the hand." },
		{ Name = "Glow", Type = "Color3", Default = Color3.fromRGB(255, 170, 60) },
		{ Name = "Surface", Type = "Enum", EnumType = "Material", Default = "Neon" },
		{ Name = "Spin", Type = "Boolean", Default = true },
		{ Name = "Sound", Type = "Asset", Description = "Played when the ring appears." },
	},
}

function Action.Run(context, params)
	local hand = if params.Hand then context.GetPart(params.Hand) else nil
	print(params.Count, params.Radius, params.Glow, params.Surface, params.Spin)
	-- params.Surface is "Neon", a string: Enum.Material[params.Surface] gives the EnumItem
	-- params.Sound is "rbxassetid://..." or nil until a block sets one
end

return Action

The Inspector shows these eight fields in this order: two pickers, a whole number field, a number field reading "studs", a colour swatch, a Material dropdown, a switch and an asset id field.

Enum ​

Actions and the other kinds declare an enum differently.

Actions pick from a Roblox enum named by EnumType. The field is a dropdown of that enum's items, and the value is stored and passed as the item's name, a string:

luau
{ Name = "Easing", Type = "Enum", EnumType = "EasingStyle", Default = "Quad" }
-- in Run: local style = Enum.EasingStyle[params.Easing]

Give Default as the item's name too. With an EnumType the Inspector doesn't know, the field is a plain text box.

Generators, constraints and drivers pick from your own Options list:

luau
{ Name = "Mode", Type = "Enum", Options = { "Follow", "Lead", "Hold" }, Default = "Follow" }
-- settings.Mode is "Follow", "Lead" or "Hold"

The value is the picked option, a string. Without a Default, it starts at the first option. A short list shows as a row of buttons (up to 3 options for a generator, up to 4 for a constraint or driver); a longer one as a dropdown. Constraints and drivers skip an Enum without Options. Not keyable.

Axis ​

Constraints only. One of "+X", "-X", "+Y", "-Y", "+Z" and "-Z", picked from a dropdown where "-Z" reads "-Z Front" (Roblox's front). The value is the string. Without a Default, it is "-Z". Not keyable.

String ​

Actions only. A one line text field; the value is a string. Without a Default, the field shows empty.

An action param with a Type the Inspector doesn't know also gets a text field, and its value is the typed string.

Color3 ​

Actions only. A swatch that opens a colour picker window; the value is a Color3. Without a Default, the field shows white.

Vector3 ​

Actions only. Three number fields, X, Y and Z; the value is a Vector3. Without a Default, the field shows 0, 0, 0. With several blocks selected, typing one component sets only that component on each.

Asset ​

Actions only. An asset id field with a thumbnail and the asset's name. It takes any asset (a sound, an image, a decal), typed as a number or pasted as a link, and stores it as "rbxassetid://<id>", which is the value the module receives.

Actor, ActorPart and Joint ​

Actions only. Pickers for the scene's cast. Each stores a string that names a role, so the same block works with whoever plays that role.

TypeValuePickerUse it with
Actora role: "Brute"a menu of the scene's actors, plus Nonecontext.GetActor(role)
ActorPart"Role/Path": "Brute/RightHand", "Brute/RightHand/RightGripAttachment"a searchable tree of each actor's contents (parts, attachments, sounds, emitters, lights), and a button to pick a part in the viewportcontext.GetPart(path)
Joint"Role/Name": "Brute/RightLowerArm"a tree of each actor's joints, as a chain from the rootthe joint's name, below

A joint is named by the part it moves (a Motor6D or AnimationConstraint), or by its own name for a Bone, as everywhere in AcesMotion. context.GetPart with a joint's value finds the part when it sits directly under the actor's model, as a character's body parts do.

A value that no longer resolves (the role is gone, or the part isn't on its actor) shows a red border in the Inspector with the reason. Right click a picker for Clear. A block that changes role while running restarts unless the module has Recast; the roles a block uses are read from these three types.

Template ​

Actions only. A field for an instance the action copies when it runs, chosen with Use selection from inside ReplicatedStorage.AcesMotionTemplates. Clicking the field selects the template in the Explorer.

The value is the instance's path as a string, starting with its service: "ReplicatedStorage/AcesMotionTemplates/Fireball". Resolve it yourself:

luau
local function resolveTemplate(templatePath: string): Instance?
	local names = string.split(templatePath, "/")
	local current: Instance? = game:GetService(names[1])
	for index = 2, #names do
		current = current and current:FindFirstChild(names[index])
	end
	return current
end

Marker ​

Actions only. A menu of the scene's markers, plus None. The field shows the marker's name and frame, but the value is the marker's permanent id, so renaming the marker keeps the block pointing at it.

Table ​

Actions only. A table of named values, edited in its own section of the Inspector below the other fields: add an entry, name it, and pick its type (Number, String, Boolean, Vector3 or Color3). The value is a { [string]: any } table; without a Default, an empty one. The built-in Event block's Payload is a Table param.

Target ​

Constraints and drivers. Something in the scene the block reads, picked like the built-in constraints' targets: a tree of the cast and the place, a viewport pick button and Use selection. A target can also be a Point, a spot with no object that you place and key. Optional = true marks a target the module works without; its empty field reads "None".

A target isn't a setting: it isn't in Settings, and Default, Min and the other value fields don't apply.

KindHow the module reads it
Constraintcontext.Targets[name], its world CFrame now; context.Sample(name, seconds) at another time in the block.
Drivercontext.Read(name, seconds?), its world CFrame; context.Distance(from, to?, seconds?) and context.Speed(name, turning?) take target names too.

A constraint with a required target unset or missing does nothing, and its Solve isn't called; an optional one arrives as nil. A driver with a required target unset does nothing too, and its Drive isn't called, so the value under it plays. A target that is set but missing from the place reads as nil in a driver's Read.

Property ​

Drivers only. A target plus one of its properties or attributes, picked in a Property dropdown under the target's field. For an object with a placement, the list starts with Placement (CFrame), and for a rig part with Pose (Transform), the joint's local value.

context.Read(name, seconds?) returns that property's value at the time, of whatever type it has. With nothing picked, it returns nil.

Defaults ​

Default is the value a block has until someone sets one. Blocks made before a param was added get it too, in Studio and in games.

  • Generators, constraints and drivers fill in a missing Default by type: 0 for numbers, false for a Boolean, the first option for an Enum, "-Z" for an Axis. Your code always receives a value.
  • Actions pass Default through as it is. A param without a Default reaches Run, Scrub and Recast as nil until the block sets a value, although its field shows a neutral value (0 within the range, false, the first enum item, white, zero, an empty table or empty text). Check for nil, or give every param a Default.

Right click a field for Reset to default (keys included), or Reset all parameters (actions) / Reset all settings (the other kinds) for every field of the block. On an action param without a Default, Reset writes the neutral value.

An action's Inspector shows a stored value only when it fits the param's current type, so changing a param's Type shows the new default in the field. The block keeps its old value until it's edited, and that old value is what the module receives.

Time settings ​

On a generator, constraint or driver, give a number Unit = "s" (stored in seconds) or Unit = "f" (stored in frames). The Inspector then shows and takes the value in the Timeline ruler's units, seconds or frames, whichever the ruler shows, and converts to the unit you declared, so your code always gets that unit.

Action params don't convert: on an action, Unit = "s" is only the text after the field.

Keying settings ​

Every number setting of a generator, and every number setting of a constraint or driver that isn't Keyable = false, gets a key diamond beside its field. Once keyed, the setting changes over the block, and its keys show on its own settings row under the block on the Timeline (open the lane's arrow). Your code receives the keyed value at that moment in settings (generators) or context.Settings (constraints and drivers).

Booleans, enums and axes are never keyable. Action params aren't keyable.

Per kind ​

Actions ​

Params may also be written as a dictionary keyed by name, an older form that still works:

luau
Params = { Part = { Type = "ActorPart" }, Speed = { Type = "Number", Default = 4 } }

Fields then show in A to Z order. In the list form they show in the order written.

Generators ​

LoopParam names the setting that sets how often the generator repeats. With Snap to Loop on, that setting is rounded so whole repeats fit the block: as a rate (repeats a second) normally, or as a length when its Unit is "s".

Some names have a built-in meaning on a generator block:

  • Influence, and Fixed1 to Fixed6 (the held channel values), are keys the block already uses, so avoid them.
  • Low, High, Speed and StepRate are safe to use: the Between Low and High, Scroll and Pattern modes keep their own values apart from yours.
  • A Number named Rate is what the Pattern mode steps at, in place of its Step rate.
  • A param named HoldEvery is drawn as Stepped's 2, 3 or 4 frames picker.

Constraints and drivers ​

The Inspector groups some params by name, as it does for the built-ins:

  • A Boolean named Name with numbers named MinName and MaxName becomes one Limit row: a checkbox labelled with the name, then the Min and Max fields, greyed while it's off.
  • Three Booleans named X, Y and Z, or PrefixX, PrefixY and PrefixZ, become one row of three checkboxes labelled "Axes" or the prefix. Their tooltips come from the built-ins' wording, not your Description.
  • A param named RelativeTo beside one named Space is drawn as the built-ins' Relative to row. Avoid that pair.

A param name can appear once: a second entry with the same Name is skipped. Targets and properties come first in the panel, then the settings in the order written.

Invalid params ​

A malformed entry is skipped without a warning:

  • an entry that isn't a table, or has no Name (or for actions, no Type string);
  • on a generator, constraint or driver, a Type that kind doesn't take, and on a constraint or driver, an Enum without Options;
  • on a constraint or driver, a repeated Name.

Other fields with the wrong type (a Min that isn't a number, a Unit that isn't a string) are dropped from the entry, which still loads. If a param you declared doesn't show in the Inspector, check its Type against the table above.

Problems with the module as a whole are reported. In Studio, its item in the Add menu is greyed with "(could not load)" and Output explains:

KindRequiredOutput says
Actiona function, or a table with Run... is tagged as an action, but: It returns neither a function nor a table with a Run function.
Generatora table with Offset... is tagged as a generator, but: It returns no table with an Offset function.
Constrainta table with Solve... is tagged as a constraint, but: It returns no table with a Solve function.
Drivera table with Drive... is tagged as a driver, but: It returns no table with a Drive function.

A module that errors while loading shows the error. In games the runtime warns AcesMotion: <module> didn't load as a generator: <why> (or constraint, or driver; actions: didn't load: <error>) and leaves the module's blocks out. RegisterGenerator, RegisterConstraint and RegisterDriver raise the same reason as an error instead.
