Timing ​

Read a scene's marker times and length without playing it, then drive a track's time from the server clock. A combat move can find out when its hit lands before the swing starts, and every machine plays the swing on the same frame.

luau
local AcesMotion = require(game.ReplicatedStorage.AcesMotion)

local hitTime = AcesMotion.GetMarkerTime(character.Moves.Punch, "Hit") -- 0.35

Each of these runs on the server or a client, with no track. They take the same first argument as Load: a scene name, a scene folder or a clip.

Times are in seconds of play time at speed 1, the time GetTime and SetTime use. A marker's Hold counts: a marker after a 0.2 s hold fires 0.2 s later. A Motion Warp timed By speed counts its keyed length, because its real length depends on where its target is when a play reaches it.

The first read of a scene works its timing out and keeps it. A scene never changes in a running game (the runtime reads each scene once), so the kept timing always matches what plays. The lists are frozen, payloads included, and every caller gets the same ones: copy one before changing it.

Reading timing ​

GetMarkers ​

luau
function AcesMotion.GetMarkers(scene: string | Instance): { Marker }

The scene's markers, sorted by time.

luau
type Marker = {
	Name: string,
	Time: number,
	Payload: { [string]: any }?,
	Role: string?, -- the actor's role, for a marker on one actor
}
luau
for _, marker in AcesMotion.GetMarkers("Combo") do
	print(marker.Name, marker.Time)
end

GetEvents ​

luau
function AcesMotion.GetEvents(scene: string | Instance): { Event }

The scene's Event blocks, sorted by time. Only named blocks on unmuted actors and lanes are listed, since those are the ones that fire.

luau
type Event = {
	Name: string,
	Time: number,
	Duration: number, -- always 0: Event blocks are instant
	Payload: { [string]: any },
	Role: string, -- the actor the block is on
}

GetMarkerTime ​

luau
function AcesMotion.GetMarkerTime(scene: string | Instance, name: string): number?

When the first marker or Event block named name fires, or nil if the scene has none. It looks at both, as GetMarkerSignal does.

luau
local hitTime = AcesMotion.GetMarkerTime(clip, "Hit") or 0.3

GetLength ​

luau
function AcesMotion.GetLength(scene: string | Instance): number

How long the scene plays at speed 1, holds included. It matches a new track's Length.

Timing a move on the server clock ​

Track:SetTimeMap pins the track's play time to workspace:GetServerTimeNow(). Read the hit time first, pick when it should land, and send both in one PlayForAll:

luau
-- Server: the swing's hit lands exactly 0.5 s from now, then the follow-through plays at speed 1.
local clip = character.Moves.Punch
local hitTime = AcesMotion.GetMarkerTime(clip, "Hit")
local now = workspace:GetServerTimeNow()

local track = AcesMotion.PlayForAll(clip, character, {
	TimeMap = {
		{ realTime = now, clipTime = 0 },
		{ realTime = now + 0.5, clipTime = hitTime },
		{ realTime = now + 0.5 + 0.1, clipTime = hitTime + 0.1 },
	},
})
track:GetMarkerSignal("Hit"):Connect(dealDamage)

Clients, late joiners too, read the same knots at their own server time, so they all show the same frame. The server's Hit fires when the mapped time reaches the marker.

A map with one knot plays at speed 1 from it. A client that hears about a play late (from your own remote) can start where everyone else is:

luau
-- Client: started at `startedAt` server time; land on the frame it's on now.
AcesMotion.Play(clip, character, { TimeMap = { { realTime = startedAt, clipTime = 0 } } })
