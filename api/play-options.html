PlayOptions ​

The third argument of Load, Play and PlayForAll, and what Track:SetOptions takes. Every field is optional.

luau
type PlayOptions = {
	Anchor: (CFrame | BasePart | Attachment)?,
	FollowAnchor: boolean?,
	Speed: number?,
	Looped: boolean?,
	Weight: number?,
	FadeIn: number?,
	FadeOut: number?,
	StartTime: number?,
	Range: ("All" | "LoopRegion" | { number })?,
	Layers: { [string]: number }?,
	LockMovement: boolean?,
	Camera: (boolean | "Manual")?,
	CameraBlendIn: number?,
	CameraBlendOut: number?,
	CameraBlendInEase: ("Smooth" | "Linear" | "EaseIn" | "EaseOut")?,
	CameraBlendOutEase: ("Smooth" | "Linear" | "EaseIn" | "EaseOut")?,
	CameraStopBlend: number?,
	Screen: boolean?,
	Effects: boolean?,
	Manual: boolean?,
	Audience: { Player }?,
	Align: { [string]: "Snap" | "Blend" | "Warp" | "None" }?,
	FreezeActors: boolean?,
	CommitRoot: boolean?,
	Templates: { [string]: Instance }?,
	Important: boolean?,
}

Placement ​

Anchor ​

Where the scene's origin goes in the world: a CFrame, or a part or attachment. A part or attachment is followed every frame: the whole scene rides it, position and rotation, as if welded to it (a moving platform, a vehicle, a mount, another character).

You often don't need it. Set Origin to Follows in the plugin (Hub > Cast > Scene origin, or a reference in the Inspector) and the scene rides that role's part in whatever cast you pass. The origin keeps the spot on the part you saw in the editor. Without the option, a play looks for, in order:

  1. the reference's own anchor (AcesMotion_AnchorRole);
  2. the scene's anchor;
  3. the scene's linked origin object, else its fixed origin.

The Anchor option beats both plugin anchors and puts the origin on the part itself, with no offset. If nobody in the cast plays the anchor role, Studio's Output warns once and the scene plays at its authored origin.

luau
AcesMotion.Play("Summon", { Caster = character }, {
	Anchor = character.HumanoidRootPart,
})

-- Two characters fighting on a moving train car
AcesMotion.PlayForAll("Duel", cast, { Anchor = trainCar.Floor })

An anchor inside an actor whose root this scene moves isn't followed (that actor would chase its own anchor): it's read once instead. If the anchor is destroyed, the scene stays where it last was. Under PlayForAll every client follows the anchor where it sees it.

FollowAnchor ​

false reads a part or attachment Anchor once, when the play starts, and leaves the scene there however the part moves afterwards.

luau
-- Play where the caster stood when the spell began, even as they walk away
AcesMotion.Play("Rune", cast, { Anchor = character.HumanoidRootPart, FollowAnchor = false })

Align ​

Per role, how an actor is brought to its authored spot when the play starts. Overrides the actor's own Align (set in the Cast tab). See Align.

luau
AcesMotion.PlayForAll("GrabSlam", cast, {
	Align = { Attacker = "None", Target = "Blend" },
})

Cameras and spawned actors always snap. Actors measured from their own root part play from where they stand.

Timing ​

Speed ​

Playback speed. 1 normal, 2 double, negative backwards (the play then starts at the end of its range).

Looped ​

Wrap at the end of the range instead of ending.

StartTime ​

Where the play begins, in seconds, clamped into the range.

luau
AcesMotion.Play("Cutscene", cast, { StartTime = 4.5 })

TimeMap ​

Knots that pin the play time to the server clock, the same as calling Track:SetTimeMap as it starts. With PlayForAll the play and its map arrive in one message. While it's set, Speed, StartTime, SetTime and StepTime don't move the time.

luau
local now = workspace:GetServerTimeNow()
AcesMotion.PlayForAll(clip, character, {
	TimeMap = { { realTime = now, clipTime = 0 }, { realTime = now + 0.5, clipTime = hitTime } },
})

Range ​

The part of the scene the play covers:

  • "All": the whole scene.
  • "LoopRegion": the scene's loop region (the whole scene when it has none).
  • { from, to }: seconds.
luau
AcesMotion.Play("Combo", cast, { Range = { 1.2, 2.8 }, Looped = true })

Manual ​

The runtime never advances the track; only StepTime and SetTime move it.

luau
local track = AcesMotion.Load("Door", { Door = door }, { Manual = true })
track:Play()
prompt.Triggered:Connect(function()
	track:StepTime(0.1)
end)

Blending ​

Weight ​

How much the scene overrides the Animator, 0 to 1. Below 1, joints and properties blend over the Animator's pose. Never applies to the root.

luau
AcesMotion.Play("Point", { Rig = character }, { Weight = 0.6 })

FadeIn ​

Seconds to fade the scene in. Also how long a Blend align slides (0.25 s when there's no FadeIn).

FadeOut ​

Seconds to fade out when the track stops, unless Stop passes its own.

luau
AcesMotion.Play("Aura", { Rig = character }, { FadeIn = 0.3, FadeOut = 0.5, Looped = true })

Layers ​

Scales scene layers' weights, by layer name. Each value multiplies that layer's authored weight (its weight curve), so 0 turns the layer off and 1 plays it as authored; a layer you leave out plays as authored. Mask, mute and solo still apply. Track:SetLayerWeight changes one mid-play.

luau
AcesMotion.Play("Walk", { Rig = character }, { Layers = { Injured = 0.5 } })

Player control ​

LockMovement ​

Locks the local player's character while it plays a scene, and unlocks it at the end. On by default; only ever affects the local player's own character.

luau
AcesMotion.Play("Emote", { Rig = character }, { LockMovement = false })

Camera ​

Whether the scene's camera actors drive the player's camera. A client Play takes it unless this is false. Under PlayForAll, clients take it only when the server passes Camera = true. A server Play never does.

luau
AcesMotion.PlayForAll("Intro", cast, { Camera = true })

Inside the scene, each switch key on the Camera track cuts to its camera, or glides there over its Blend (set on the key in the Inspector).

"Manual": the runtime still computes the scene's camera every frame (shots, blends, kicks) but leaves the player's camera alone. Read it with Track:GetCamera and apply it yourself, mixed with your own camera or not. AttachCamera hands the camera to the runtime later, mid-play.

luau
local track = AcesMotion.Play("Cutscene", cast, { Camera = "Manual" })
RunService:BindToRenderStep("MyCutsceneCamera", Enum.RenderPriority.Camera.Value + 1, function()
	local shot = track:GetCamera()
	if shot then
		camera.CFrame = shot.CFrame * myShakeOffset
		camera.FieldOfView = shot.FieldOfView
	end
end)

CameraBlendIn ​

Seconds the view glides from the player's camera into the scene's first shot when the scene takes the camera. 0 cuts. A first switch key with its own Blend uses that instead. Left out, the scene's own Blend in applies (press the Camera row on the Timeline: the Inspector's Camera in game panel).

CameraBlendOut ​

Seconds the view glides from the scene's last shot back to the player's camera when the scene lets it go. The player's camera keeps working while it glides, so the view lands exactly where that camera is, even if the character moved during the scene or is walking. 0 cuts. Left out, the scene's own Blend out applies.

luau
AcesMotion.Play("Finisher", cast, { CameraBlendIn = 0.4, CameraBlendOut = 0.8 })

Camera blend eases ​

CameraBlendInEase and CameraBlendOutEase: how each glide speeds up and slows down. "Smooth" (the default) eases in and out, "EaseIn" starts slow, "EaseOut" ends slow, "Linear" keeps one speed.

CameraStopBlend ​

Seconds the view glides back when the scene is stopped before its end (Stop). 0 snaps back. Left out, the scene's When stopped early applies: like the end (the default), snap back, or blend back over its own time and ease.

luau
-- Glide in, but snap back when the player skips it
local track = AcesMotion.Play("Intro", cast, { CameraBlendIn = 0.6, CameraBlendOut = 0.6, CameraStopBlend = 0 })
skipButton.Activated:Connect(function()
	track:Stop()
end)

Screen ​

Whether the scene's screen effects (letterbox bars, vignette, blur, fades, colour correction, bloom and each camera's depth of field) draw on the player's screen while the scene drives the camera. They ease in and out with the camera's blends, and colour correction, blur and bloom add on top of the game's own Lighting effects. false plays the camera without them. With Camera = "Manual" nothing is drawn: read them from Track:GetCamera.

luau
-- The scene's camera, but the game keeps its own screen effects
local track = AcesMotion.Play("Intro", cast, { Screen = false })

Effects ​

Whether the scene's AcesFX blocks play. They play on each client through the game's AcesFX runtime (a ModuleScript tagged AcesFXRuntime); without one they do nothing and a warning shows once. false skips every AcesFX block, for a play whose effects your own code fires instead.

luau
-- The animation alone: the game plays its own effects
local track = AcesMotion.Play("Slash", cast, { Effects = false })

Server and networking ​

Audience ​

PlayForAll only: the players who play it. Everyone when left out. Late joiners outside the audience don't get it.

luau
AcesMotion.PlayForAll("TeamIntro", cast, { Audience = redTeam:GetPlayers() })

FreezeActors ​

Server only. Anchors the moved actors' root parts on the server while the play runs, so physics doesn't fight what clients see. Player characters are never frozen.

CommitRoot ​

Server only. When the play ends, moves each moved actor to where the clients left it (its root keys, attach keys and root blocks such as a Motion Warp all count), then unanchors it, so nothing snaps back.

luau
-- An NPC that should stay where the scene drops it
AcesMotion.PlayForAll("Knockback", { Target = npc }, { FreezeActors = true, CommitRoot = true })

Spawned actors ​

Templates ​

A template per spawned role, used instead of the scene's own, so one scene can play with different looks as long as the templates share a skeleton. Under PlayForAll they must be somewhere clients can see (ReplicatedStorage).

luau
AcesMotion.PlayForAll("Slash", { Attacker = character }, {
	Templates = { SlashFX = ReplicatedStorage.Skins[equippedSkin].SlashFX },
})

Important ​

Poses every actor of this play every frame, wherever they are and however busy the frame is. Without it, offscreen actors don't pose and far ones pose less often (see Configure); their clock, markers and events always run at full rate. Use it for a hero, a boss, or a close-up the camera cuts to.

luau
AcesMotion.Play("BossIntro", { Boss = boss }, { Important = true })
