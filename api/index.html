Runtime API ​

The AcesMotion runtime is the ModuleScript your game requires to play scenes. The plugin installs it as ReplicatedStorage.AcesMotion (Settings > About > Install runtime). It's MIT licensed and self-contained.

luau
local AcesMotion = require(game.ReplicatedStorage.AcesMotion)

local track = AcesMotion.Play("Slam", { Attacker = attacker, Target = target })
track.MarkerReached:Connect(function(markerName, payload)
	print("reached", markerName)
end)

Every client requires it once

A LocalScript in StarterPlayerScripts with require(game.ReplicatedStorage.AcesMotion) is enough. The server only needs it for PlayForAll, server Play, and relaying a client's Play on a model it owns to the other clients.

RegisterGeneratorfunctionRegisters a custom generator by name.

EvaluatefunctionEvery actor's pose at a time, without writing anything.
ConfigurefunctionRuntime settings: MaxDistance, level of detail, frame budget, client replication.

The types are exported, so you can annotate your code:

luau
local AcesMotion = require(game.ReplicatedStorage.AcesMotion)

local options: AcesMotion.PlayOptions = { Looped = true, FadeIn = 0.2 }
local track: AcesMotion.Track = AcesMotion.Load("Idle", { Rig = rig }, options)
