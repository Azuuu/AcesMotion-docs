Types and enums ​

Everything the runtime takes and returns, plus the names it looks for in your place. Enums are plain Luau string unions.

Exported types ​

AcesMotion.Track, AcesMotion.PlayOptions, AcesMotion.Cast, AcesMotion.Pose and AcesMotion.Config are exported for your annotations.

luau
local AcesMotion = require(game.ReplicatedStorage.AcesMotion)
type Track = AcesMotion.Track

local tracks: { [Player]: Track } = {}

Cast ​

luau
type Cast = { [string]: Instance | { any } }

Who plays each role, by the role names in the Cast tab.

  • A role you leave out plays on its fallback (usually the stand-in you animated).
  • A role with no instance and no fallback is skipped, with a warning once in Studio.
  • A list fills a role with several instances. An actor set to Repeat Per target plays one copy per item, each landing on its own item; any other actor plays on the first item.
luau
local cast: AcesMotion.Cast = {
	Attacker = attacker,
	Target = target,
}

Pose ​

luau
type Pose = { [string]: any } -- track path -> value

What Evaluate returns for each role: every animated track path and its value at that time.

Config ​

luau
type Config = {
	MaxDistance: number?,
	ClientReplication: boolean?,
	Lod: boolean?,
	FrameBudget: number?,
	LodTiers: { { Distance: number, Rate: number } }?,
	CullOffscreen: boolean?,
	LodFullCount: number?,
}

What Configure takes. Every field is optional; the Configure table lists what each does and its default.

CameraEase ​

luau
type CameraEase = "Smooth" | "Linear" | "EaseIn" | "EaseOut"

How a camera glide speeds up and slows down: the CameraBlendInEase and CameraBlendOutEase options, and the scene's own blends.

ValueWhat it does
"Smooth"Eases in and out. The default.
"Linear"One speed all the way.
"EaseIn"Starts slow.
"EaseOut"Ends slow.

Lens ​

luau
type Lens = { FocusDistance: number, InFocusRadius: number, NearBlur: number, FarBlur: number }

The live camera's depth of field, as Track:GetCamera reports it in Lens. The fields match a DepthOfFieldEffect's FocusDistance, InFocusRadius, NearIntensity and FarIntensity.

FieldRangeDefault
FocusDistance0 to 1000 studs20; a camera focused on an actor reports the distance to it now.
InFocusRadius0 to 500 studs10
NearBlur0 to 10
FarBlur0 to 10

Depth of field is off while both blurs are 0.

Align ​

luau
type Align = "Snap" | "Blend" | "Warp" | "None"

How an actor is brought to its authored spot when a play starts. Only actors with a root track align.

ValueWhat it does
"Snap"Teleports to the authored spot. Cameras and spawned actors always snap.
"Blend"Slides there over FadeIn (0.25 s without one). The default for rigs and models.
"Warp"Kept for older scenes: plays as "Blend". To bend an actor's motion onto a target, use a Motion Warp block.
"None"Plays where it stands, with the scene's motion relative to there.

Track states ​

The states a Track goes through. They are internal, so read them through IsPlaying and the signals instead of relying on the names.

StateMeaning
LoadedMade by Load, never played. Nothing bound.
WaitingPlay was called; the first frame hasn't run yet. IsPlaying is true.
PlayingRunning. Started fired on the way in.
EndingStopped with a fade: the time is frozen while the pose fades out.
DoneFinished. Ended fired. Play starts it again.

Play modes ​

How much of a scene a machine plays. Internal, but useful for understanding where code runs.

ModeWhereWrites
FullA client's own Play; every client under PlayForAll; the server under its own Play.Everything it may. On the server: roots and properties, not joints.
JointsA client's copy of a server Play.Joints, plus the local player's own root.
TimingThe server's copy of a PlayForAll.Nothing. It runs the clock so markers and Event blocks fire in server code.

Markers and Event blocks fire in every mode. Custom actions run only in Full.

Track paths ​

How a scene names what it animates on an actor: the keys of a Pose. Instance paths are names joined by /, relative to the actor.

PathAnimates
joint:RightUpperArmThe Motor6D or AnimationConstraint whose moved part is RightUpperArm, or the Bone of that name.
rootThe actor's own CFrame (a model's pivot, a part's or camera's CFrame), relative to the scene origin.
prop:Torso/SlashEmitter.RateA property. prop:.Transparency is the actor's own property; a Model's Scale is its ScaleTo scale.
attr:Torso/SlashEmitter.PowerAn attribute.
call:Head/Roar.PlayA method run at the keys (Play, Stop, Emit, Clear, Pause). Nothing is written.
luau
local poses = AcesMotion.Evaluate("Slam", 1.0, cast)
for trackPath, value in poses.Attacker do
	print(trackPath, value)
end

Scene data enums ​

What scenes store. You only meet these if you read scene data, but they explain what the editor's options mean.

EnumValues
InterpolationConstant, Linear, Cubic, Eased, Bezier
Tangent modeAuto, Smooth, Flat, Linear, Broken
Key typeKey, Breakdown, Hold (display and filtering only)
Pre / post infinityHold, Cycle, CycleOffset
Rotation modeEuler, Quaternion
Actor kindRig, Model, Part, Camera, Instance, Spawned, Screen (the scene's screen effects)
Origin mode (scene)Scene, RootPart, Mixed
Root space (actor, in Mixed scenes)Scene, RootPart
Value typeNumber, Vector2, Vector3, Color3, UDim, UDim2, CFrame, NumberRange, NumberSequence, ColorSequence, Bool, Enum, Text, Asset, Call
Layer modeOverride, Additive
Generator blendAdd, Multiply, Replace

Time inside scene data is stored in ticks, 6000 per second. The runtime API always uses seconds.
