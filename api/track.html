Track ​

A scene loaded for a cast, like Roblox's AnimationTrack. AcesMotion.Load, Play and PlayForAll return one.

luau
local track = AcesMotion.Load("Slam", { Attacker = npc, Target = enemy })
track:Play()
  • Play after the track ends plays it again; Play while it plays restarts it.
  • Signals stay connected across plays.
  • SetSpeed, SetLooped, SetCast, SetOptions and the other setters work before and during a play, and keep their value for the next play. They never change the options table you passed.
  • Play time follows the shared server clock (workspace:GetServerTimeNow()), never the frame delta, so a hitch on one machine doesn't leave it behind.

Properties ​

Length ​

luau
track.Length: number

The play's length in seconds: the scene's length, stretched or shortened by its Motion Warps timed by speed and its markers' holds, and lasting until the last repeated copy ends. A warp timed by speed is worked out when the play reaches it, so Length can change mid-play; LengthChanged fires when it does.

luau
local progress = track:GetTime() / track.Length

Playback ​

Play ​

luau
function Track:Play()

Plays from the start, or from StartTime. On a client it plays locally; on the server it writes roots and properties there and sends the joints to every client. Called while playing, it restarts at once (Stopped and Ended fire, then the new play begins).

Errors if the track was destroyed.

PlayForAll ​

luau
function Track:PlayForAll()

Server only. Every client (or the Audience option) plays the scene; the server keeps the clock. See Networking.

Errors on a client, or if the track was destroyed.

Stop ​

luau
function Track:Stop(fadeOut: number?)

Stops the play. With a fade (fadeOut, else the FadeOut option), the time freezes and the pose fades out from where it stopped; Ended fires when the fade is over. Joints go back to what the Animator gives them; roots and properties keep the last value written.

luau
track:Stop(0.25) -- fade out over a quarter second
track:Stop(0) -- stop at once, ignoring the FadeOut option

Pause ​

luau
function Track:Pause()

Freezes the time where the clock is now. A paused track still counts as playing (IsPlaying is true).

Resume ​

luau
function Track:Resume()

Continues from where it paused.

luau
-- Hit-stop: freeze the scene for 80 ms on impact
track:GetMarkerSignal("Hit"):Connect(function()
	track:Pause()
	task.wait(0.08)
	track:Resume()
end)

Time ​

SetTime ​

luau
function Track:SetTime(seconds: number)

Jumps to seconds of play time, forward or back, and plays on from there. On a looped track the time wraps into the range; otherwise it's held at the ends. Instant blocks in between don't fire; duration blocks that the new time lands inside start. Only while playing (right after Play is fine); use the StartTime option to choose where a play begins.

luau
track:Play()
track:SetTime(1.5) -- skip the wind-up

StepTime ​

luau
function Track:StepTime(deltaSeconds: number)

Moves the time by deltaSeconds (negative goes backwards) and fires everything crossed, in order. Pair it with the Manual option to drive a track yourself.

luau
local track = AcesMotion.Load("Finisher", cast, { Manual = true })
track:Play()
RunService.Heartbeat:Connect(function(deltaTime)
	track:StepTime(deltaTime * slowMotionFactor)
end)

GetTime ​

luau
function Track:GetTime(): number

The current play time in seconds from the scene's start.

SetSpeed ​

luau
function Track:SetSpeed(speed: number)

Playback speed. 1 is normal, 0.5 half speed, negative plays backwards. Takes effect from now, mid-play too.

luau
track:SetSpeed(0.2) -- slow motion
task.wait(1)
track:SetSpeed(1)

SetLooped ​

luau
function Track:SetLooped(looped: boolean)

Loop on: the play wraps at the end of its range (Looped fires). Turned off mid-play: it ends when it gets there.

Blending ​

SetWeight ​

luau
function Track:SetWeight(weight: number)

How much the scene overrides the Animator, 0 to 1. Below 1, joints and properties blend from the Animator's pose toward the scene's, so a scene can sit on top of idle or walk. Never applies to the root.

luau
track:SetWeight(0.5)

SetLayerWeight ​

luau
function Track:SetLayerWeight(layerName: string, weight: number)

Scales the weight of the scene layer named layerName by weight, from the next frame. The layer's own weight curve, mask, mute and solo still apply; 0 turns the layer off and 1 plays it as authored. Same as the Layers option, one layer at a time. A server track sends the change to the clients playing it.

luau
-- Fade a "Tired" layer in as stamina drops
track:SetLayerWeight("Tired", 1 - stamina / maxStamina)

Camera ​

SetCamera ​

luau
function Track:SetCamera(enabled: boolean | "Manual")

Whether the scene's camera actors drive the player's camera. On by default for a client Play, off for PlayForAll (turn it on with the Camera option on the server). Switched off mid-play, the camera goes back to the game. "Manual" computes the scene's camera without touching the player's: read it with GetCamera.

luau
-- Let the player skip the cinematic camera
skipButton.Activated:Connect(function()
	track:SetCamera(false)
end)

HasCamera ​

luau
function Track:HasCamera(): boolean

True when the scene animates a camera (a camera actor that isn't muted).

GetCamera ​

luau
function Track:GetCamera(): { CFrame: CFrame, FieldOfView: number, Shot: string, Attached: boolean, Screen: { [string]: any }, Lens: Lens }?

The scene's camera after this frame's pose: where it is, its field of view, the live camera actor's role (Shot), and whether the runtime is driving the player's camera with it (Attached). Nil when no shot is live here (a server, Camera = false, before the first switch key). With Camera = "Manual", read it each frame (after Enum.RenderPriority.Camera) and apply it however your game likes.

Screen holds the scene's screen effects this frame, neutral when the scene has none: BarsTop and BarsBottom (% of the screen's height), BarsColor, Vignette (0 to 1), VignetteColor, Blur (a BlurEffect's Size), Fade (0 to 1) and FadeColor, Brightness, Contrast, Saturation, Tint, BloomIntensity, BloomSize and BloomThreshold. Lens is the live camera's depth of field: { FocusDistance: number, InFocusRadius: number, NearBlur: number, FarBlur: number } (a DepthOfFieldEffect's FocusDistance, InFocusRadius, NearIntensity and FarIntensity; a camera focused on an actor gives the distance to it now).

luau
-- A Manual camera that draws the scene's fade with the game's own UI
RunService:BindToRenderStep("MyCutsceneCamera", Enum.RenderPriority.Camera.Value + 1, function()
	local shot = track:GetCamera()
	if shot then
		workspace.CurrentCamera.CFrame = shot.CFrame
		fadeFrame.BackgroundColor3 = shot.Screen.FadeColor
		fadeFrame.BackgroundTransparency = 1 - shot.Screen.Fade
	end
end)

AttachCamera ​

luau
function Track:AttachCamera(blendSeconds: number?)

Lets the runtime drive the player's camera from now, gliding in over blendSeconds (when left out, the play's or the scene's blend in; 0 cuts). Use it after playing with Camera = "Manual" or false, for example once a character reaches a spot. Fires CameraAttached.

DetachCamera ​

luau
function Track:DetachCamera(blendSeconds: number?)

Gives the player's camera back from now, gliding over blendSeconds (when left out, the blend out), while the scene keeps playing. The scene's camera is still computed, so GetCamera keeps working (the track switches to "Manual"). Fires CameraDetached.

luau
-- Let the player look around halfway through, then take the camera back
track:GetMarkerSignal("FreeLook"):Connect(function()
	track:DetachCamera(0.5)
	task.delay(3, function()
		track:AttachCamera(0.5)
	end)
end)

Cast and options ​

SetCast ​

luau
function Track:SetCast(cast: Cast)

Changes who plays the roles. Roles you leave out keep their instance. Mid-play, each changed role lets go of its old instance (joints back to the Animator, movement unlocked) and the new one carries on from now. Running action blocks that use a changed role get their Recast, or restart.

luau
-- The target died mid-combo: carry on with the next one
track:SetCast({ Target = nextEnemy })

SetOptions ​

luau
function Track:SetOptions(options: PlayOptions)

Changes any PlayOptions, mid-play too. Looped, Speed, Weight, Camera and Layers go through their setters. Range moves the time into the new range; Anchor and Align bind every actor again from now (a new part or attachment anchor is followed from there, unless FollowAnchor is false); LockMovement locks or frees the local character; Manual stops or resumes following the clock. StartTime and Audience apply from the next Play.

luau
track:SetOptions({ Anchor = newSpot, FadeOut = 0.5 })

State ​

IsPlaying ​

luau
function Track:IsPlaying(): boolean

True from Play until the track stops or ends. A paused track is still playing.

Binds ​

luau
function Track:Binds(instance: Instance): boolean

True when the track is playing instance as one of its actors right now (a cast member, a filled role or the camera). GetPlaying uses it to find the tracks playing an actor.

luau
if track:Binds(character) then
	track:Stop(0.2)
end

Signals ​

Signals are Signal objects: :Connect(fn), :Once(fn), :Wait(), :DisconnectAll().

Started ​

luau
track.Started: Signal<>

Fires on the first frame after Play, so connecting right after Play still catches it.

Stopped ​

luau
track.Stopped: Signal<>

Fires when the play stops: Stop was called, or a play that doesn't loop reached its end. A fade out may still be running.

Ended ​

luau
track.Ended: Signal<>

Fires once the play is completely done: fade out over, joints released, roots committed. An Ended handler can Play the track again.

luau
track.Ended:Connect(function()
	character.Humanoid.WalkSpeed = 16
end)

Looped ​

luau
track.Looped: Signal<>

Fires each time a looping play wraps around.

LengthChanged ​

luau
track.LengthChanged: Signal<number>

Fires with the new Length when it changes, typically when the play reaches a Motion Warp timed by speed and works it out from where its start and target really are (the same way on the server and every client).

luau
track.LengthChanged:Connect(function(length)
	progressBar.Size = UDim2.fromScale(track:GetTime() / length, 1)
end)

CameraAttached ​

luau
track.CameraAttached: Signal<>

The runtime took the player's camera (the play started with the camera on, or AttachCamera).

CameraDetached ​

luau
track.CameraDetached: Signal<>

The runtime gave the player's camera back (the end, Stop, DetachCamera, the camera switched off).

ShotChanged ​

luau
track.ShotChanged: Signal<string?>

The live camera actor changed: its role, or nil between shots. Fires with Camera = "Manual" too.

MarkerReached ​

luau
track.MarkerReached: Signal<(markerName: string, payload: { [string]: any })>

Fires when the play reaches a marker or an Event block, with its name and payload (an empty table when it has none). Fires in every play mode, so on the server under PlayForAll too.

luau
track.MarkerReached:Connect(function(markerName, payload)
	if markerName == "Hit" then
		target.Humanoid:TakeDamage(payload.Damage or 10)
	end
end)

GetMarkerSignal ​

luau
function Track:GetMarkerSignal(markerName: string): Signal<(payload: { [string]: any })>

A signal for one marker or Event block name, fired with its payload. The same signal every call.

luau
track:GetMarkerSignal("Hit"):Connect(function(payload)
	spawnImpactEffect(payload)
end)

Cleanup ​

Destroy ​

luau
function Track:Destroy()

Stops at once and disconnects every signal. The track can't play again. Works with Trove (trove:Add(track)).

luau
local trove = Trove.new()
local track = trove:Add(AcesMotion.Load("Aura", { Rig = character }, { Looped = true }))
track:Play()
-- later: trove:Destroy() stops and cleans it up

Lifecycle ​

Started fires on entering Playing, Stopped on leaving it, and Ended at Done. See Track states.
