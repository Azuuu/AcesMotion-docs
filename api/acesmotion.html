AcesMotion ​

The module itself: require(game.ReplicatedStorage.AcesMotion).

luau
local AcesMotion = require(game.ReplicatedStorage.AcesMotion)

Properties ​

Version ​

luau
AcesMotion.Version: string

The release this runtime belongs to, like "0.3.2". The plugin and the runtime share one version.

FormatVersion ​

luau
AcesMotion.FormatVersion: number

The newest scene format this runtime reads. A scene saved with a newer AcesMotion is refused by name; update the runtime from Settings > About.

luau
print(`AcesMotion {AcesMotion.Version}, reads scene format {AcesMotion.FormatVersion}`)

Playing scenes ​

Load ​

luau
function AcesMotion.Load(scene: string | Instance, cast: Cast | Instance | string?, options: PlayOptions?): Track

Loads a scene for a cast without playing it, like Animator:LoadAnimation. Nothing is bound, no camera is taken and no movement is locked until you call Play or PlayForAll.

ParameterTypeDescription
scenestring | InstanceThe scene's name, its folder, a reference, or a model whose reference you name in cast. Names are searched in ReplicatedStorage.AcesMotionScenes, then every folder given to RegisterFolder.
castCast?Who plays each role. A role you leave out plays on its fallback. With a reference, just the model; with a model, the reference's name.
optionsPlayOptions?How it plays. The track keeps its own copy, so your table is never changed.

Returns a Track in the Loaded state.

Errors at once if the scene doesn't exist, or was saved in a newer format than this runtime reads.

luau
local slam = AcesMotion.Load("Slam", { Attacker = npc })
slam:SetLooped(true)
slam:Play()

Play ​

luau
function AcesMotion.Play(scene: string | Instance, cast: Cast | Instance | string?, options: PlayOptions?): Track

Load, then Track:Play().

  • On a client it plays the whole scene locally, and takes the camera when the scene has camera actors (unless Camera = false).
  • On the server it writes roots and properties on the server (Roblox replicates those) and sends the joints to every client, because a joint's Transform never replicates.
luau
-- LocalScript: a wave only this player sees
local track = AcesMotion.Play("Wave", { Rig = game.Players.LocalPlayer.Character })
track.Ended:Wait()

PlayForAll ​

luau
function AcesMotion.PlayForAll(scene: string | Instance, cast: Cast | Instance | string?, options: PlayOptions?): Track

Server only. Every client (or only options.Audience) plays the whole scene. The server runs only the clock, so markers and Event blocks fire in server code, at the same moment clients see them.

luau
-- Script (server)
local track = AcesMotion.PlayForAll("Intro", { Hero = hero, Villain = villain }, { Camera = true })
track.MarkerReached:Connect(function(markerName)
	if markerName == "Explosion" then
		destroyBridge()
	end
end)
track.Ended:Wait()
startRound()

FreezeActors and CommitRoot default to on, so moved characters are held on the server while it plays and land where clients left them. See Networking.

Preload ​

luau
function AcesMotion.Preload(sceneNames: { string | Instance })

Decodes scenes ahead of time, so their first play doesn't decompress anything.

Errors like Load for a scene that doesn't exist or can't be read.

luau
AcesMotion.Preload({ "Intro", "Uppercut", "Summon" })

References ​

A reference lets each NPC carry its moves the way a model carries cloned Animation instances, so your code never names a scene. It's a Configuration tagged AcesMotionClip and named for the move, with these attributes:

AttributeTypeDescription
AcesMotion_SceneIdstringThe scene's permanent id (its folder's AcesMotion_Id). Renaming or moving the scene doesn't break the reference.
AcesMotion_Rolestring?The role the model plays. A scene with one role doesn't need it.
AcesMotion_SceneNamestring?The scene's name when the reference was made, for people and error messages.
AcesMotion_AnchorRolestring?The role whose part the scene rides, instead of the scene's own anchor. "" plays at the authored origin; not set uses the scene's anchor. Set it in the Inspector.
AcesMotion_AnchorPartstring?The part of that role, as a path under it (Torso, HumanoidRootPart/RootAttachment). Not set: its HumanoidRootPart, else its PrimaryPart.
AcesMotion_AnchorOffsetCFrame?Where the origin sits on that part. The Inspector sets it so the scene plays where the editor shows it.
<Role>Instance?Who plays that role, one attribute per role, named after it. Characters an attribute name can't hold become _, so role Bone Rig is Bone_Rig. A target inside the same model follows the model when it's cloned.

Names starting with AcesMotion_ are reserved. Any other attribute that holds an instance is read as a cast entry; attributes of other types are ignored, so you can keep your own data on the reference.

Make references with Create reference in the plugin. With nothing selected it puts one in ReplicatedStorage for you to drag into a model or template; with NPCs selected in the Explorer, each gets one. They clone with the model like any other child. A new reference's cast is empty, so roles you don't cast in code play their fallback.

luau
-- The reference named Punch anywhere inside npc; npc plays its role
AcesMotion.Play(npc, "Punch")

-- The same, when you already have the reference
AcesMotion.Play(npc.Moves.Punch, npc)

-- Cast the roles yourself
AcesMotion.Play(npc.Moves.Grab, { Attacker = npc, Target = enemy })

Each role goes to the first of these that has someone:

  1. the cast table you pass in code;
  2. the reference's cast entries (a target that's gone or streamed out is skipped);
  3. the model, if the reference's AcesMotion_Role names this role;
  4. the model, if this is the only role still empty;
  5. the actor's game target or fallback, as for any play.

If two or more roles are still empty and no role is set, the call errors and lists them.

The scene plays at the Anchor option if you pass one, else at the reference's anchor, else at the scene's anchor, else at its authored origin. So a reference anchored to its character role plays on that character with no options at all.

The runtime looks a reference's scene up by id in the folders above and in every folder tagged AcesMotionScene. If two scenes share an id because one was copied in the Explorer (AcesMotion's Duplicate gives copies a new id), it warns once and plays the first it finds.

Plays from a reference replicate, relay and reach late joiners like plays by name, because the network sends the scene's id along with its name.

FindById ​

luau
function AcesMotion.FindById(sceneId: string): Folder?

The scene folder with this permanent id, or nil.

GetClip ​

luau
function AcesMotion.GetClip(model: Instance, clipName: string): Instance?

The reference named clipName anywhere inside model, or nil. Handy to check what moves a model has before playing one.

luau
if AcesMotion.GetClip(npc, "Kick") then
	AcesMotion.Play(npc, "Kick")
end

RegisterFolder ​

luau
function AcesMotion.RegisterFolder(folder: Instance)

Adds a folder (and its subfolders) to search for scenes by name, after ReplicatedStorage.AcesMotionScenes and the folders registered before it. Register it on every side that plays by name. A client can only play scenes it can see, so the folder can't be in ServerStorage.

luau
AcesMotion.RegisterFolder(game.ReplicatedStorage.Combat.Scenes)
local track = AcesMotion.Play("Uppercut", cast)

Managing tracks ​

GetPlaying ​

luau
function AcesMotion.GetPlaying(actor: Instance?): { Track }

Every playing track on this side, or only those playing actor. A paused track counts as playing.

luau
if #AcesMotion.GetPlaying(character) > 0 then
	return -- already in a scene
end

StopAll ​

luau
function AcesMotion.StopAll(actor: Instance?)

Stops every playing track, or only those playing actor. Each track fades out by its own FadeOut option.

luau
humanoid.Died:Connect(function()
	AcesMotion.StopAll(character)
end)

Events ​

OnEvent ​

luau
function AcesMotion.OnEvent(eventName: string, callback: (track: Track, payload: { [string]: any }) -> ()): () -> ()

Calls callback(track, payload) whenever an Event block or a marker named eventName fires in any scene on this side (server or client). Each callback runs in its own thread. Returns a function that disconnects it.

luau
local disconnect = AcesMotion.OnEvent("Footstep", function(track, payload)
	playFootstepSound(payload.Foot)
end)

-- later
disconnect()

For one track only, use MarkerReached or GetMarkerSignal.

Extending ​

RegisterAction ​

luau
function AcesMotion.RegisterAction(actionName: string, actionModule: ActionModule | (context, params) -> (() -> ())?)

Registers a custom action for action blocks whose Action is actionName. Pass the full contract table, or just a function (an instant action's Run). You rarely need this: every ModuleScript tagged AcesMotionAction registers itself under its module name. A name registered here first wins over a tagged module.

luau
AcesMotion.RegisterAction("ScreenFlash", function(context, params)
	flashScreen(params.Color or Color3.new(1, 1, 1))
end)

RegisterGenerator ​

luau
function AcesMotion.RegisterGenerator(generatorName: string, generatorModule: { [string]: any })

Registers a custom generator for generator blocks whose generator is generatorName. Pass the same table a generator module returns: Offset(seconds, duration, channel, settings, noise) -> number, plus optional Description, Kinds, Blend, Params and DefaultAxes. You rarely need this: every ModuleScript tagged AcesMotionGenerator registers itself under its module name. A name registered here first wins over a tagged module. A built-in generator's name (Shake, Spin) is never replaced; registering one does nothing.

ParameterTypeDescription
generatorNamestringThe generator's name in the scene, which is its module name.
generatorModule{ [string]: any }The generator table.

Errors at once if generatorModule isn't a table with an Offset function.

Register it on the server and on every client, as the tag would.

luau
AcesMotion.RegisterGenerator("HoverBob", require(script.HoverBob))

RegisterConstraint ​

luau
function AcesMotion.RegisterConstraint(constraintName: string, constraintModule: { [string]: any })

Registers a custom constraint for constraint blocks named constraintName. Pass the same table a constraint module returns: Solve(world, context) -> CFrame, plus optional Description, Params and Drives. Every ModuleScript tagged AcesMotionConstraint registers itself under its module name. A name registered here first wins over a tagged module. A built-in constraint's name is never replaced; registering one does nothing.

ParameterTypeDescription
constraintNamestringThe constraint's name in the scene, which is its module name.
constraintModule{ [string]: any }The constraint table.

Errors at once if constraintModule isn't a table with a Solve function. A Solve that errors or returns no CFrame leaves the subject where it was, with one warning.

luau
AcesMotion.RegisterConstraint("LookBetween", require(script.LookBetween))

RegisterDriver ​

luau
function AcesMotion.RegisterDriver(driverName: string, driverModule: { [string]: any })

Registers a custom driver for driver blocks named driverName. Pass the same table a driver module returns: Drive(context) -> value (a number for a number row or one channel, else a whole value of the row's type), plus optional Description and Params (Number, Integer, Boolean, Enum, Target and Property). Every ModuleScript tagged AcesMotionDriver registers itself under its module name. A name registered here first wins over a tagged module. A built-in driver's name is never replaced; registering one does nothing.

ParameterTypeDescription
driverNamestringThe driver's name in the scene, which is its module name.
driverModule{ [string]: any }The driver table.

Errors at once if driverModule isn't a table with a Drive function. A Drive that errors or returns the wrong type changes nothing, with one warning.

luau
AcesMotion.RegisterDriver("SpringFollow", require(script.SpringFollow))

RegisterModifier ​

luau
function AcesMotion.RegisterModifier(modifierName: string, modifierModule: { [string]: any })

Registers a custom modifier. Modifiers are only stored for now: modifier stacks aren't evaluated yet. ModuleScripts tagged AcesMotionModifier register themselves.

Utilities ​

Evaluate ​

luau
function AcesMotion.Evaluate(scene: string | Instance, seconds: number, cast: Cast?): { [string]: Pose }

Every actor's pose at seconds, by role. Each Pose maps a track path to its value. Nothing is written to any instance. Muted actors are left out.

luau
local poses = AcesMotion.Evaluate("Slam", 0.5, { Attacker = npc })
local swordColor = poses.Attacker["prop:Sword.Color"]
local armRotation = poses.Attacker["joint:RightUpperArm"]

Useful for hitboxes that follow an authored swing, NPC logic that reads where a scene will put a character, or tests.

Configure ​

luau
function AcesMotion.Configure(config: Config)

Runtime settings for this side, from a Config. Fields you leave out keep their value.

FieldTypeDefaultDescription
MaxDistancenumber?offClients skip evaluating scenes whose anchor is farther than this from the camera, and pick them up at the right time when close again. A scene that drives the camera and a scene in a ViewportFrame are never skipped. 0 or less turns it off.
Lodboolean?trueClients don't pose offscreen actors. With up to LodFullCount actors on screen, every visible one poses every frame. With more (a crowd), far ones pose less often, and less often still as the crowd grows: every frame within 80 studs of the camera, then 30, 20 and 12 times a second to 160, 320 and beyond (on phones: 60, then 30, 20 and 10 to 120, 250 and beyond), each actor on its own beat. Distances count as they look: a zoomed-in camera brings actors closer. A skipped frame holds the pose. The clock, markers and events always run every frame. Your own character, cameras and Important plays always pose every frame, and so does an actor with a driver, a custom constraint or a constraint aimed at another role (constraints aimed at itself, such as foot Locks, don't count). A rig in a ViewportFrame is judged by its frame: it rests while the frame is hidden or scrolled away, and on screen counts as far away as a rig that size would look.
LodTiers{ { Distance: number, Rate: number } }?80 / 60, 160 / 30, 320 / 20, beyond / 12 (phones: 60 / 60, 120 / 30, 250 / 20, beyond / 10)Your own tiers, nearest first: within Distance studs an actor poses Rate times a second (60 or more is every frame); past the last distance the last rate holds. Distances must go up. nil isn't a reset: pass the defaults to go back.
LodFullCountnumber?64 (50 on phones)How many actors may be on screen before the distance tiers start. A crowd past it gets coarser tiers as it grows (four times the count, distances count double); it switches back below 80% of the count.
CullOffscreenboolean?truefalse keeps actors off screen posing at their distance's rate (mirrors, minimaps, split screens).
FrameBudgetnumber?1.5 on phones, 4 elsewhereHow many milliseconds a frame AcesMotion may take on a client. While it takes more, the distances beyond the first tier stretch (up to 4 times) so far actors drop to lower rates; they ease back when it takes less. Actors in the first tier always pose every frame. 0 or less goes back to the default.
ClientReplicationboolean?trueA client's Play on a model it owns (its character, or anything whose physics it owns) plays on every other client, checked by the server. Set it the same on the server and every client. See Networking.

Errors if LodTiers is empty, a tier lacks a Distance or a Rate above 0, or the distances don't go up.

luau
-- LocalScript
AcesMotion.Configure({ MaxDistance = 400 })

-- A top-down game: tighter tiers, and nothing drops to 5 a second
AcesMotion.Configure({
	LodTiers = {
		{ Distance = 25, Rate = 60 },
		{ Distance = 60, Rate = 30 },
		{ Distance = 120, Rate = 15 },
	},
	FrameBudget = 2,
})
