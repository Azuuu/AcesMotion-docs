Custom actions ​

A custom action is your own code, placed on the Timeline as a block on an action track. It runs when the playhead enters the block, in Studio's preview and in games.

New to custom actions? Custom actions walks through writing one, with a complete example. Custom generators, constraints and drivers are tagged ModuleScripts too, with their own register functions: RegisterGenerator, RegisterConstraint and RegisterDriver.

Making one ​

  • In the Timeline, right click an action track > Add block > New custom action... It writes a typed, commented template as a ModuleScript where you've selected in the Explorer (else ReplicatedStorage), already tagged.
  • Or tag any ModuleScript AcesMotionAction. It registers under its module name (keep names unique), wherever it lives. Keep it where both the server and clients can require it, such as ReplicatedStorage.
  • Or call AcesMotion.RegisterAction in code.

The contract ​

luau
--!strict
return {
	Name = "Toggle Trail",
	Description = "Turns a trail on for the block.", -- optional: the block's tooltip
	Icon = "rbxassetid://0", -- optional
	HasDuration = true, -- false: an instant action that fires once
	Params = {
		{ Name = "Part", Type = "ActorPart", Description = "The part holding the trail." },
		{ Name = "TrailName", Type = "String", Default = "SwordTrail" },
	},
	Run = function(context, params)
		local part = context.GetPart(params.Part)
		local trail = part and part:FindFirstChild(params.TrailName)
		if not trail then
			return nil
		end
		trail.Enabled = true
		return function() -- cleanup: the playhead left the block, or the scene stopped
			trail.Enabled = false
		end
	end,
}
FieldTypeDescription
NamestringShown on blocks and in the Add block menu.
Descriptionstring?The tooltip for the block and its menu item.
Iconstring?An image id for the block.
HasDurationbooleantrue: the block has a length; Run on enter, cleanup on leave. false: an instant chip that fires once.
Params{ Param }The block's settings, drawn as Inspector fields in this order.
Run(context, params) -> (() -> ())?Called when the playhead enters the block. Return a cleanup function, or nothing.
Scrub(context, params, localSeconds) -> ()?Optional. Called every step while inside, for actions that must follow the playhead exactly.
Recast(context, params, changedRoles) -> ()?Optional. A role this block uses got a new instance while it runs. Without it, the block restarts.

A quick instant action can be just a function:

luau
return function(context, params)
	print("Hit at frame", context.Frame)
end

Every param takes Name, Type, and optional Default and Description (its Inspector tooltip). A param without a Default arrives as nil until the block sets it. Module params covers every type in full: its Inspector field, its default, and how generators, constraints and drivers differ.

luau
Run = function(context, params)
	local hand = context.GetPart("Caster/RightHand")
	local beam = ReplicatedStorage.Effects.Beam:Clone()
	beam.Parent = hand
	context.Trove:Add(beam) -- destroyed when the block ends
	if context.IsPreview then
		return nil -- skip gameplay in Studio
	end
	dealDamageAlong(beam)
	return nil
end,

When it runs ​

  • While playing, Run is called when the playhead enters a block, and its cleanup when it leaves.
  • While scrubbing in Studio, blocks with a duration run and clean up as the playhead moves in and out. Instant blocks fire only while playing, unless Settings > Actions > Fire instant actions while scrubbing is on.
  • SetTime doesn't fire instant blocks in between; duration blocks that the new time is inside start. StepTime fires everything crossed, in order, in either direction.
  • On a late join or stream-in, duration blocks covering the current time start; past instant blocks don't fire.
  • Actions run in Full mode only: a client's own Play, every client under PlayForAll, the server under its own Play. They never run in the server's timing copy of PlayForAll.
  • Errors in Run, its cleanup, Scrub and Recast are caught, so one broken action can't stop a scene. Each is warned in Output; Scrub runs every step, so its error is warned once per block.
  • Params left out of a block take their Default before Run, Scrub and Recast see them.

Event blocks ​

The built-in Event action has two params, Name and Payload. It fires MarkerReached, GetMarkerSignal and OnEvent, on the server too. Use it for gameplay moments; use custom actions for effects.

luau
AcesMotion.OnEvent("Shake", function(track, payload)
	shakeCamera(payload.Intensity or 1)
end)
