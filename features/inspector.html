The Inspector ​

The Inspector shows the settings of whatever you selected last and lets you key them. Pick a part of an actor and you get its properties, each with a key diamond. Press a key, a block, a marker or a camera shot on the Timeline and you get that item's panel instead. Use it whenever you want to animate a value that isn't a pose: a light's brightness, a particle's colour, a camera's field of view.

Opening it ​

The Inspector is a tab in the Hub. Right click the tab and choose Pop out Inspector to give it a window of its own; right click it again in that window, or click the return button at the right of its tab strip, to send it back.

Pressing something on the Timeline (a block, a marker, a switch key, a spawned actor's Lifetime bar) switches the Hub to the Inspector tab. Selecting things in Studio's Explorer or clicking a row header never switches tabs. When the Inspector tab is hidden and what it would show changes, the tab gets a small accent dot.

What it shows ​

The last selection wins. Whatever you select afterwards (keys, rows, a viewport pick, a Studio selection inside an actor) takes the Inspector over.

You selectThe Inspector shows
An actor row, a joint, the root, a property row, or a part in the viewportThe property panel for that instance
KeysThe Key panel: frame, value, key type and interpolation
An action block, generator, constraint, driver or Motion WarpThat block's panel
A marker flag, a camera shot, an attach keyThe Marker, Camera switch or Attach panel
A layer or a versionThe layer panel or the Version panel
An audio clip or a lane headerThe clip or lane panel

Every panel that shows one thing (a block, a clip, a marker, a switch key) has a trash button in its header that deletes it, with the same Delete on a right click of the header.

The property panel ​

The header has the instance's class icon, its name and a class chip. Under it, the picker shows the instance's path inside the actor. Click it for a searchable tree of everything in the actor, with a count of animated properties on each instance.

Search properties searches the whole actor. This instance's matches come first, then "Elsewhere on {actor}" with a Show arrow that jumps to the other instance. The key button beside the search is Animated only: it lists just the properties with keys, on every instance of the actor, and stays on until you turn it off.

Properties are grouped by Studio category, A to Z inside each, in sections that fold (remembered per class). A Calls section comes first on objects with methods, and Attributes comes last. The Game target, Attached and Stack sections sit at the end. Rows that can't be animated are left out: read-only and deprecated properties, BrickColor, Font, PhysicalProperties and velocities. On a part inside a rig, Position and Rotation aren't listed, because you pose that part in the viewport.

Editors by type ​

TypeEditor

Bool, Enum, TextA toggle, a menu, a text box

Number fields work the same everywhere. Drag past 3 px to scrub, hold Shift for 10x finer steps or Ctrl for whole numbers, and press Esc to put the value back. A click without a drag types, and you can type arithmetic on the value shown: +5, *2, /2, -=3.

Key diamonds ​

DiamondMeansClick it to
HollowNot animatedAdd a track and key the current value
Bottom half filledAnimated, no key on this frameKey it here
FilledKeyed on this frameRemove this key (the track stays)
OrangeChanged, not keyed yetKey the change

K with the pointer over a row keys it too. With a track and Auto-key on, editing a value keys it at the playhead. With Auto-key off, the change is a temporary pose that the next playhead move drops. A property with no track changes the instance for good, as one undo step.

Edits you make in Studio's own Properties window to a property that already has a track are recorded the same way.

Row menu and copying values ​

Right click anywhere on a row for Key at playhead, Remove from timeline, Copy, Paste, Reset to default and Reset to value before animating. Shift+C copies the value of the row under the pointer and Shift+V pastes it onto another row of the same type. Paste as driver turns the copied property into a Copy driver on this one.

Calls and attributes ​

The Calls section keys methods as events: an emitter's Emit() (with a Count from 1 to 50 and an optional Life), a sound's Play() (with Count and Stop at), and Stop(), Clear() and Pause(). See Action blocks, events and audio for how they draw on the Timeline.

The + on the Attributes header adds an attribute of any type Roblox allows. Attributes animate like properties, in rows named @Name. An Instance attribute holds a reference, so it has no key diamond.

Editing several objects ​

Select keys on several objects, several Timeline rows, or up to 500 instances in Studio, and the header reads "ParticleEmitter ×3". Values that differ read Mixed. Typing sets only the part you changed on every object, dragging moves each by the same amount, and the whole edit is one undo step. A half-filled diamond means only some objects have a key here ("2 of 3 objects have a key here"). Objects of different classes show only the properties they share.

Tips ​

  • While the Timeline plays or scrubs, values and diamonds follow the playhead up to 20 times a second and show the exact frame once it stops.
  • The Inspector remembers which sections you folded, in every kind of panel.
  • Picking an actor as a whole scrolls to its Stack section, which lists every generator, constraint, driver and warp on the actor in the order they run.

Compared to Roblox's Animation Editor ​

Roblox's Animation Editor animates a rig's joints and face. It has no way to key a light's Brightness, a ParticleEmitter's Color or a camera's FieldOfView. You can change those in Studio's Properties window, but the change isn't keyed. The AcesMotion Inspector gives those properties key diamonds, along with attributes and method calls, on any instance in the scene's cast.
