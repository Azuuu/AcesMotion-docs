# AcesMotion

AcesMotion is a Roblox Studio animation plugin whose animations adapt to your game. A scene is cast by role, so it plays on whichever characters the game passes in. Motion Warp makes a punch or a throw land where the target really is, and constraints and drivers react to the live scene. Rigs, cameras, visual effects and sound share one Timeline, and games play the scenes with a small MIT-licensed runtime, with nothing to upload.

- Documentation: <https://azuuu.github.io/AcesMotion-docs/>

- What changed in each release: [CHANGELOG.md](CHANGELOG.md)

## Report a bug or ask for a feature

[Open an issue](https://github.com/Azuuu/AcesMotion-docs/issues/new/choose) and pick a template. For a bug, the version (Settings > About) and the steps that cause it are the two things needed to fix it. A short video or the scene's text (Export > Scene as text) also helps.

## This repository

It holds the built documentation site (the `gh-pages` branch), this changelog and the issue tracker. The plugin's source isn't public. The runtime that games install comes with the plugin and is MIT licensed.
